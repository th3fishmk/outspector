# Outspector

This simple program allows you to pull and add licenses, using github api, to a writable directory

## example

```bash
# Adds a mit license
outspector mit

# Adds the default license
outspector

# Set your username/org name to use within this program
outspector --set-name 'username'

# Configure the default license
outspector --set-default 'mit'
```

Simple enough!
